# finish-task


- Verify acceptance criteria one by one.
- Run required quality gates.
- Update task status and `tasks/CURRENT.md`.
- Write compact handoff, changed files, test evidence, and residual risks.
- Do not commit, push, release, deploy, or run production migrations without approval.
