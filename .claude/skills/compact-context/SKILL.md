# compact-context


Run repository/diff/log summarizers as needed. Produce only:
- goal and acceptance criteria;
- changed and relevant files;
- decisions and constraints;
- commands/tests and outcomes;
- unresolved risks and next exact action.
Store it in the task file or `tasks/HANDOFF.md`.
