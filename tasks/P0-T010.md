# P0-T010: Data-quality gate

- Status: planned
- Model tier: sonnet (mechanical subtasks: haiku)
- Approval required: only if an important action is discovered
- Dependencies: see `tasks/BACKLOG.md`

## Goal

Produce a quality report and block downstream ML below threshold.

## Scope

Implement only this task. Do not begin dependent tasks implicitly.

## Acceptance criteria

- [x] Report is machine- and human-readable
- [x] Thresholds are configurable
- [x] ML pipeline refuses failed datasets

## Evidence

### Changed files

- `src/boat_prediction/quality.py` (new): `score_report()` combines the
  five weighted axes from §10.2 (completeness 25, uniqueness 15,
  validity 20, consistency 15, point_in_time 25) into a `QualityReport`
  with `.to_dict()`/`.to_json()` (machine-readable) and `.render()`
  (human-readable text). `DEFAULT_THRESHOLDS` implements the guide's
  95/90/80 bands; callers may pass their own `thresholds`.
  `require_allowed(report, purpose="prediction"|"research")` is the
  enforcement point: raises `QualityGateError` for `blocked` on either
  purpose, and additionally for `research_only` on `purpose="prediction"`.
- `tests/test_quality.py` (new, 15 tests).

### Commands and tests

- `python -m unittest discover -s tests -p 'test_*.py'` — 91 passed
- `python scripts/quality_gate.py` — passed

### Decisions and risks

- "ML pipeline refuses failed datasets" is split into two purposes
  (`prediction` vs `research`) rather than one boolean, because the
  guide's own table distinguishes `research_only` (allowed for research,
  refused for live prediction) from `blocked` (refused for both). A
  single-purpose gate would have collapsed that distinction.
  - No actual ML pipeline exists yet to call `require_allowed()` — this
  is the reusable enforcement primitive; wiring it into a real
  train/predict entrypoint is P1 work, not repeated here.
- Axis *scores* (how completeness/uniqueness/etc. are computed from a
  real dataset) are out of scope — that's the job of P0-T002/T006/T007's
  outputs feeding into this gate, which isn't wired up yet since there is
  no real ingested dataset to score.
- Naming: this module is `src/boat_prediction/quality.py`, distinct from
  the unrelated `scripts/quality_gate.py` (repo-template self-check) to
  avoid confusing the two.
