## Evidence

### Changed files

- `src/boat_prediction/second_place.py` (new): `ConditionalSecondPlaceModel.fit()`
  takes `(first_place, second_place)` observation pairs (rejecting
  `first == second` as invalid input data, not silently dropping it) and
  builds Laplace-smoothed per-first-place conditional frequencies.
  `predict(first_place)` always sets `probs[first_place] = 0.0` exactly
  (never estimated) and normalizes the remaining 5 lanes to sum to 1.0.
  `evaluate_with_folds()` is the only scoring entry point and takes
  P1-T002 `Fold` objects directly — there is no parameter through which
  a random split could be substituted.
- `tests/test_second_place.py` (new, 13 tests).

### Commands and tests

- `python -m unittest discover -s tests -p 'test_*.py'` — 262 passed
- `python scripts/quality_gate.py` — passed

### Decisions and risks

- Continues under the same **P3 sequencing exception** recorded in
  `tasks/P3-T001.md` (P2 forward-test stability not yet demonstrated;
  synthetic data only).
- "Temporal validation is used" is enforced by API shape
  (`evaluate_with_folds` only accepts `Fold`s, reusing P1-T002) rather
  than a runtime check that could be bypassed — there's no alternative
  evaluation function in this module that takes raw indices or allows
  shuffling.
- Reused `LANES` from `baseline.py` instead of redefining the 1-6 lane
  range a second time.
