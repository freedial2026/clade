## Evidence

### Changed files

- `src/boat_prediction/expected_value.py` (new): `uncertainty_margin()`
  implements a documented, versioned formula
  (`UNCERTAINTY_MARGIN_FORMULA_VERSION = "uncertainty_margin_v1"`):
  `calibration_error + sample_size_weight/sqrt(n_samples) +
  variance_weight*model_std` — combining the three inputs §14.3 names
  (calibration error, sample size, model variance) without the guide
  pinning an exact formula, so this one is explicitly versioned for
  future change. `compute_conservative_ev()` applies
  `conservative_probability = max(0, calibrated_probability - margin)`
  and `conservative_ev = conservative_probability * odds` (§14.4,
  literal formula — an expected-payout multiple, not net profit; no `-1`
  term per the guide), returning an `ExpectedValueReport` that keeps
  `raw_probability`/`raw_ev` alongside `conservative_probability`/
  `conservative_ev` and the `formula_version` used.
- `tests/test_expected_value.py` (new, 15 tests).

### Commands and tests

- `python -m unittest discover -s tests -p 'test_*.py'` — 193 passed
- `python scripts/quality_gate.py` — passed

### Decisions and risks

- No abstention/buy threshold exists in this module at all — comparing
  `conservative_ev` against a cutoff to decide buy-vs-abstain is
  explicitly P2-T004's job, kept separate per
  docs/PROJECT_PROFILE.md ("action policy remain separate").
- `sample_size_weight`/`variance_weight` are caller-supplied with
  defaults of `1.0` rather than being fixed; a real deployment would set
  these from backtested calibration behavior, which doesn't exist yet
  (no real data).
- `conservative_ev = conservative_probability * odds` follows the
  guide's literal text, which reads as an expected payout multiple
  (breakeven at 1.0) rather than net expected profit
  (`probability*odds - 1`, breakeven at 0). Flagged in case this was a
  simplification in the source doc rather than the intended formula —
  worth confirming before this feeds a real abstention threshold.
