### Decisions and risks

- Calibrator is a dependency-free histogram-binning approach rather than
  `sklearn.isotonic.IsotonicRegression`/Platt scaling, even though
  scikit-learn is now installed (P1-T004). Chose this to keep
  calibration logic auditable in plain Python and not coupled to a
  specific library's API; revisit if binning proves too coarse once
  real data is available.
- "Untouched holdout remains untouched" is enforced by API shape
  (`fit_and_evaluate` only ever calls `.fit()` on the fit split) plus a
  test proving it by object identity — not by a runtime lock/guard
  against accidentally calling `.fit()` directly on holdout data outside
  this helper, which remains possible if a caller misuses `BinnedCalibrator`
  directly instead of going through `fit_and_evaluate`.
- No real predictions/data exist yet; all values are synthetic.
