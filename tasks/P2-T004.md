### Decisions and risks

- **Documented gap in the source guide**: §15.2's fifth rule
  ("conservative EV below threshold → abstain") has no matching code in
  §15.1's list. Added `EV_CONSERVATIVE_BELOW_THRESHOLD` to fill it,
  following the existing `PREFIX_DESCRIPTION` naming convention, rather
  than silently reusing an unrelated existing code or leaving that rule
  unimplementable.
- Only the five §15.2 "initial" rules are wired into
  `evaluate_abstention()`; several §15.1 codes (`DQ_POINT_IN_TIME_VIOLATION`,
  `MD_OUT_OF_DISTRIBUTION`, `OD_ODDS_STALE`, `OD_ODDS_SHARP_CHANGE`,
  `RC_*`, `RM_*`) exist in the documented vocabulary but have no
  corresponding check yet — the guide itself scopes §15.2 as "P2では以下
  を採用する" (P2 adopts *these*), implying the rest come later; not
  built here to avoid inventing undocumented trigger conditions.
- Each missing-field case independently contributes
  `DQ_MISSING_REQUIRED_DATA`; duplicates are collapsed (`dict.fromkeys`)
  so three missing fields don't produce three identical codes.
