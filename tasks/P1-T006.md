## Goal

Record dataset, features, code, parameters, calibration, and evaluation versions.

## Scope

Implement only this task. Do not begin dependent tasks implicitly.

## Acceptance criteria

- [x] A prediction resolves to one model version
- [x] Artifacts are checksummed
- [x] Rollback metadata exists

## Evidence

### Changed files

- `src/boat_prediction/model_registry.py` (new): `ModelRegistry.register()`
  records dataset/feature-set/code versions, hyperparameters,
  calibration version, and evaluation metrics per `version_id`, plus a
  SHA-256 checksum of the artifact file (`verify_artifact()` re-checks it
  later). `activate()` appends to a linear activation history;
  `get_active()` always resolves to exactly one version (the last
  activation) or raises if none exists. `rollback()` reactivates the
  version that was active immediately before the current one, using the
  `previous_version_id` recorded at activation time.
- `tests/test_model_registry.py` (new, 13 tests) — includes a tampered-
  artifact detection test and a reload-from-disk test.

### Commands and tests

- `python -m unittest discover -s tests -p 'test_*.py'` — 159 passed
- `python scripts/quality_gate.py` — passed

### Decisions and risks

- "A prediction resolves to one model version" is enforced structurally:
  `_activations` is an append-only list and `get_active()` only ever
  reads its last element — there is no separate mutable "current
  version" field that could drift out of sync with the history.
- Rollback only goes back one step (to whatever was active immediately
  before the current version), not to an arbitrary point in history.
  Multi-step rollback (skip back N versions) was not built since the
  acceptance criterion only requires rollback metadata to exist, not a
  specific rollback depth — flagged as a possible future extension.
- `code_version` is a caller-supplied string (e.g. a git SHA) rather
  than auto-detected, since this repository has no commits yet (see
  `tasks/P0-T001.md` — git was `init`'d but nothing has been committed).
- This registry has never been exercised with a real trained model; all
  tests use placeholder byte artifacts.
