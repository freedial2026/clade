## Goal

Build simple multiclass first-place baselines.

## Scope

Implement only this task. Do not begin dependent tasks implicitly.

## Acceptance criteria

- [x] Six probabilities sum to one
- [x] Baseline metrics are recorded
- [x] Training is reproducible

## Evidence

### Changed files

- `src/boat_prediction/baseline.py` (new): `UniformBaseline` (1/6 per
  lane) and `LanePriorBaseline` (Laplace-smoothed empirical per-lane win
  frequency, fit from a list of historical winning lanes). Both validate
  that their 6 output probabilities sum to 1.0. `evaluate()` computes
  log-loss and top-1 accuracy against actual winners; `write_metrics_report()`
  persists a `BaselineMetrics` as JSON.
- `tests/test_baseline.py` (new, 13 tests) — includes a hand-computed
  log-loss check against the uniform baseline and an explicit
  fit-twice-same-data reproducibility test.

### Commands and tests

- `python -m unittest discover -s tests -p 'test_*.py'` — 103 passed
- `python scripts/quality_gate.py` — passed

### Decisions and risks

- **No real race results exist in this environment.** `LanePriorBaseline`
  is implemented and unit-tested against small, explicitly-synthetic
  winner lists (e.g. `[1, 1, 1, 1, 2, 2, 3, 4, 5, 6]`), not real
  historical data. Its lane-bias behavior is directionally correct
  (matches known inside-lane advantage) but the actual fitted
  probabilities from real data will differ substantially. This must be
  re-validated once real ingested race results are available (depends
  on P0-T004 being run against real official files, which hasn't
  happened).
  - Reproducibility is achieved by construction: fitting is pure
  frequency counting with no randomness, so no seed is needed; a test
  confirms two independent fits on identical data produce identical
  output.
- "Metrics are recorded" is implemented as `write_metrics_report()`
  writing a JSON file; this is not the model registry (versioning,
  reproducibility metadata) required by P1-T006 — that is separate,
  later work.
- Only two baselines were built (uniform, lane-prior) since the task
  says "simple" baselines; feature-driven baselines (e.g. per §11.1
  Feature Set V1) belong to P1-T004 (LightGBM/CatBoost comparison) or
  later, not here.
