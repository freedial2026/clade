# 承認マトリクス

| 操作 | 既定 | 条件 |
|---|---|---|
| 読取・検索・差分確認 | 不要 | 秘密ファイルを除く |
| Pythonによる機械処理 | 不要 | ローカル、可逆、入力検証済み |
| テスト・lint・型検査 | 不要 | 本番データや課金資源を使わない |
| 内部リファクタリング | 不要 | 公開挙動と互換性を維持 |
| 明白な不具合修正 | 不要 | タスク範囲内、テスト追加 |
| ローカルDB作成・破棄 | 不要 | 使い捨てデータのみ |
| Git commit | 必要 | 差分・テスト・メッセージ提示後 |
| Git push / merge / tag | 必要 | 共有履歴・外部公開に影響 |
| 本番デプロイ | 必要 | ロールバックと監視を提示 |
| 本番マイグレーション | 必要 | バックアップ・dry-run・停止条件 |
| 認証・権限・暗号変更 | 必要 | セキュリティレビュー必須 |
| 個人・機密・本番データ利用 | 必要 | 目的・最小化・保存・削除を確認 |
| データ取得方式の規約判断 | 必要 | 公式規約・許諾を確認 |
| DB製品・主要FW変更 | 必要 | ADRと移行コストを提示 |
| モデル本番昇格 | 必要 | 独立検証・paper運用・rollback |
| 自動購入・決済・投票 | 必要かつ別プロジェクト | 法務・依存対策・リスク管理 |
